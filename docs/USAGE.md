# 使用说明

当前应用1.14.0配套仪表App1.14.0/RWVF，需同时更新APK和仪表App，保留数据和已有系统授权。MCU、参考OS和Boot保持原件。

1. 首次使用按说明安装配套仪表包、连接数据线，并允许系统调试及访问仪表的弹窗。
2. 在“应用”中选择应用，回到“投屏”点击底部的“开始投屏”。连接会自动准备；启动中可取消，投屏中同一个按钮变为“停止投屏”。
3. 投屏时仍从原应用图标打开并操作。回桌面或打开其他应用，仪表继续显示当次应用。更换应用会先结束旧投屏；一次只投一个。
4. “设置”中选择全屏或小窗；画面设置下次投屏生效。“更多画面选项”保留完整显示/填满区域，后者在比例不一致时可能裁掉边缘。应用深浅只控制本应用，仪表与地图各按自身设置。
5. 首页“仪表投屏连接”开关可保持数据线连接切换。关闭会先停止投屏，再请求恢复仪表U盘；是否恢复以仪表提示为准。
6. 在“应用”或“设置”打开“应用内投屏接入”，复制`fission_dashcast_meter`，到支持外部屏幕的应用发送；开关不改变仪表，关闭不打断当前投屏。定制地图缺原按钮时，无障碍服务提供仅地图可见的备用入口。
7. 有问题到“帮助”导出日志，文件保存在车机下载目录。技术详情、开发工具在更多支持选项，日常无需操作。

应用偏好、收藏与已有ADB身份均保留。界面未额外增加授权/付费或累计时长限制。未知清理结果仍会阻止继续投屏，按提示恢复；断线后先检查数据线并重新连接，不用技术术语掩盖仍需处理的状态。[本轮界面调整与验证边界](PRODUCT_1.13.0.md)。

## 0.5.0持续小窗验收

先完成短时检查，再设置持续时长600秒，点“开始持续投屏”，保持停稳并确认可见动态画面及不遮挡。打开导航，确认投屏不中断；可回应用或从通知栏停止。状态只有在采集EXIT、接收端STOP及USB退出都确认后才结束；ACK/visible属性不是人工画面证明。

10分钟通过后再做1800秒；连续启动/停止三次、界面重建后查看状态/停止、结束后拔线恢复Host并用普通U盘验证。无视频Host/NCM循环和重复NCM按钮单独回归。持续模式不保存视频文件；时长1～1800秒不是10秒片段循环重连。

USB断开只中止当前会话，不自动换模式或重连。出现QUARANTINED/清理未确认应停止测试，确认正常恢复后重启仪表和APK进程，不为重试删锁或强杀共享服务。此版本未做道路使用或安全层级验收。

## 0.6.0比例与地图区域

中央640×240窗口没有完成动态告警隔离；固件存在中央WarnText节点，不称其安全区。**仅停稳/可恢复台架测试，不进行道路测试。**模式只影响持续投屏，旧5秒诊断/测试图保持原显示对照。

1. 同签名覆盖APK，保留ADB身份；仪表已经是0.5.0则不重刷。沿用已通过的授权/唯一NCM连接，不为每次比对反复切模式。
2. 在“持续投屏画面比例”选择完整画面保持比例fit（默认）、中心裁剪crop、自定义地图区域region或原拉伸stretch。region输入左/上/右/下百分比，0～100、右大于左/下大于上，每边跨度至少5%；这是手动区域，不是自动识别地图。
3. 本轮勾选台架/停稳且无关键告警的确认，先用20～30秒对照。fit完整源、可能留边；crop填满但舍弃上下/两侧；region保留指定地图区域。确认弹窗显示冻结选项，开始后切其他应用可看到该区域内容，不能在运行中改变选项。
4. 停止并确认窗口退出/STOPPED后再改模式重测；比较实际比例、边缘是否裁错/旧画面残留、文字清晰度，以及仪表关键信息。发现遮挡、告警、画面异常或清理未确认立即停止，不靠确认勾选宣称安全。
5. 导出日志中检查CAPTURE_SELECTION、PROJECTION_CONFIG、SHELL_CAPTURE_GEOMETRY及退出记录；实际主屏尺寸用于换算百分比，不硬编码所有车均1920×1080。新几何通过后再补600/1800秒自然结束、后台、再用及视频后拔线Host回归。

原0.5.0已现场通过两轮动态画面/后台/停止及Host/U盘；新增几何需要单独实显验收，不把已通过项重新列为待开发，也不把桌面黑边模拟当OEM SurfaceFlinger已验证。

日志可能含网络地址/设备路径/密钥指纹，发公开Issue前先人工脱敏。不要把签名私钥、ADB私钥、原厂/参考固件或全量系统日志放进源码/Issue；可刷包分发单独审核来源和测试范围。不要求仪表U盘日志回收。
