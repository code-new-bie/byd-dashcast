# 使用说明

适用于 APK 1.38.0 / code95，配套仪表 1.38.0/RWVI。车机桌面上的名称是“仪表投屏”。

## 安装

1. **仪表包**：把配套完整包解压后的 `release/` 目录放到 U 盘，按仪表正常升级流程刷写整套文件。刷写前备份原包，在停稳的车或台架上进行。包内 MCU 和版本文件就是基础包的原件，os.sv 只多了本模块的启动项（见[构建文档](BUILD.md)的“刷机包组成”一节）。
2. **APK**：交付包含 `dashcast-1.38.0-debug.apk`。APK 和仪表包要用同一版本（投屏端口和配对标记两端一致才能投屏）。覆盖安装保留应用数据和 ADB 身份，不需要卸载。
3. 连接车机和仪表之间的数据线。第一次使用时，系统会询问是否“允许 USB 调试”，勾选“始终允许”后确认。访问仪表 USB 由本应用自动授权，不再弹窗。

## 日常使用

1. 在“应用”页点“选择并开始”，然后在“投屏”页等待并操作；已经选好的应用也可以直接在投屏页点开始。应用没启动也可以从这里打开，等待时可以取消，不用先回桌面。
2. 投屏期间，仍然可以从原应用图标打开它进行操作。回桌面或打开其他应用，仪表继续显示这个应用。一次只投一个应用，换应用时会先结束上一个。
3. 投屏页可以选全屏或小窗。窗口按画面比例尽量放大，不拉伸也不裁切；控制区会根据屏幕放在窗口下方或侧边。页面上的按钮可以停止、更换应用，或把“返回”交给应用处理。浏览应用列表不会停止当前投屏，确认更换后才切换。
4. 首页的“投屏模式”开关决定仪表的模式：打开后仪表切到投屏连接，App 自动保持连接（打开 App、开机、插上数据线时都会自动连上）；关闭后先停止投屏，再请求仪表恢复 U 盘。没连上时开关不会自己弹回，随时可以关掉恢复 U 盘。左上角圆点显示连接状态：灰色 U 盘模式、黄色闪烁连接中、绿色已连接、绿色带光圈投屏中、红色没连上。点圆点可看详情并重新连接。
5. 两个开关（“投屏模式”和“应用内投屏接入”）的选择会被记住，重启应用后自动恢复。
6. 界面颜色默认跟随系统：车机切换深色或浅色，本应用随之切换；也可以在设置里固定为深色或浅色。仪表和地图各自按自己的设置切换深浅。
7. 设置里的“开机启动”开启后，开机时自动恢复上次开着的两个开关，不打开界面，也不自动开始投屏。车机默认禁止第三方应用自启动，需要在原车自启动管理中允许本应用（设置里有跳转按钮）。

## 应用内投屏接入（外部应用）

1. 在“设置”里打开“应用内投屏接入”，等显示就绪、复制按钮可用后，复制屏幕名 `fission_dashcast_meter`，在支持外部屏幕的应用里选择它发送画面。
2. 已经有普通投屏时，外部应用的请求会等它结束后再开始，同一时间只运行一个视频会话。这个开关本身不改变仪表，关闭也不会打断正在进行的投屏。
3. 待机屏按投屏页选的全屏或小窗建立：全屏 1912×498，小窗 1870×810（都含边缘的淡出带）。画面一律铺满，边缘淡入外框，贴边的界面会变淡。空闲时切换模式会按新尺寸重建。接入还在启动时切换，这次切换可能不生效，关掉再打开一次接入即可。
4. 打开接入时，会通过已授权的调试连接打开本应用的无障碍服务，用来识别定制地图自带的仪表按钮；已开启的其他无障碍服务不受影响。

**定制版高德地图**：地图自带的仪表按钮点一次投到仪表，再点一次停止。这个按钮只有在地图服务启动时已经存在接入屏幕，并且车辆报告的导航类型大于 0 时才会显示，所以要先打开接入，再强行停止地图，然后重新打开。地图不显示这个按钮时，可以在本应用“应用”页点“仪表地图”。

## 出问题时

- 到“设置”的“帮助与反馈”导出日志，文件保存在下载目录，也可以查看技术详情。
- 断线后先检查数据线，再重新连接。
- 上次投屏没结束干净时，App 会自动清理（页面显示“正在清理上次投屏”），通常不需要操作；需要时会自动重启自己。清理没成功时，点主按钮“重启应用”；仍不行再重启仪表。
- 仪表重要信息异常、投屏窗口不退出或模式异常时，停止使用，必要时刷回原包。
