# 0.9.1：五秒背景功能首测

此候选真实修改仪表HMI，APK显式触发背景抑制，仪表独立计时最多5秒后恢复。**不是完整全屏；尚未实车，禁止道路使用。**视频继续使用原640×240小窗，必须配套APK/仪表App。

## 实现范围

- 精确HMI版本的四处钩子，新增代码仅用已确认零填充，增加132字节BSS并同步末尾符号。原厂getter验证Screen/RootPage/Content/BG_New及BG/Sky两个无子节点叶子；不匹配不抑制。
- 仅跳过背景子树/根画刷，改变本次清屏alpha；不永久改主题、整个窗口alpha、车型配置、车速/挡位/告警或KZB。原厂业务照常更新。
- 固定截止、pid/epoch/拥有者、双序列锁、过期拒绝、重复不可续时及停止/重建恢复。APK断线不延长期限；HMI挂起期间不能保证物理刷新，不能宣称硬实时安全保护。
- DCV1 type10/BGP1固定操作/5秒，无任意路径、命令、地址接口，不切USB模式。普通视频保留；此候选隐藏旧F1/type9按钮。
- startup-background-poc.ksh只创建可选4096字节RAM记录，已有对象不截断，失败不阻断USB入口。App内仍安装为startup.ksh；原startup.ksh源码保留，旧包装器不变。
- 原便携C控制器仍为独立模块，本PoC不冒称它已被完整交叉编译接入。MCU、参考OS、Boot、USB角色模块不改。

## 证据

私有332项Java/47套、22项ARM/Thumb（含1000轮）、5项隔离启动及30帧高清契约/软件MD5/独立成品审计通过。原连接分发入口也实际执行type10、HELLO前返回BGP1而不启动媒体。系统/文件/时钟/媒体为替身；不是QNX冷启动、真实画面/透明合成、动态告警或道路安全证明。公开独立测试结果另见VALIDATION。0.8.2现场已验证基线继续保留，不因本候选重开原USB/视频故障。

## 停车首测

1. 保留旧可用配套及正常回退入口；成对更新0.9.1，正常重启。FULL携带未改OS/原国内MCU，升级器可能再次刷原件。
2. **先不点背景按钮**，确认原厂画面、车速/挡位/可用告警正常。
3. 沿用原NCM接线和USB授权，勾选配套/停稳；已有NCM勿重复切换。
4. 点击“背景功能验证：抑制5秒并自动恢复”。观察背景确实变化约5秒并恢复，原生关键信息全程保留。日志先HMI_ACTIVE，后NATIVE_RESTORED及两个背景跳过计数；日志不代替观察。
5. 恢复正常后重复一次，再独立回归10秒小窗测试图/主屏/副屏和停止退窗。不支持在已有视频会话中同时点背景测试。
6. 一键导出APK日志到下载目录；正常退出、拔线，再Host验U盘。不删guard、不强制切换。

背景无变化、前景缺失或未恢复时停止重试/投屏，正常重启；仍异常用保留配套回退。完整全屏、硬件层序/alpha及所有动态告警仍未验收。
