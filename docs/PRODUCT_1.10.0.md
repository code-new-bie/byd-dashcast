# 1.10.0：持续输出、冷启动与异形融合

本版 APK code49 必须配套 RWV6 仪表 App。不能沿用 RWV5 仪表假装获得曲边、功率单位或底板修复；MCU、已匹配参考 OS、Boot、USB角色与媒体协议不变。同签名覆盖 APK，保留数据及 ADB 身份。

## 改动及依据

| 问题 | 修复归属与处理 |
|---|---|
| 定制地图数秒退出 | APK：现场是编码 PTS 超过两秒断档、随后清理完成，不是 NCM 或清理隔离。GL 对静止的已确认业务画面按实际时间有界重绘，不依赖 OEM 编码器的 repeat-previous-frame；不复制编码 AU、不伪造编码时间轴或宣称画面运动30FPS。 |
| 首次点投屏无画面，重试才好 | APK：转发启动页可结束并将业务任务建到主屏，旧启动检查只等副屏任务。现在仅在冷启动窗口接受唯一、新建、同用户/同包且稳定的主屏继任，再精确托管。已绑定任务的 root/user/display 防护不放松。现场没有 Java 崩溃堆栈，不把该修复冒称覆盖任意闪退。 |
| 打开无障碍退出 | APK：检查设置入口能否访问，并捕获缺 Activity/权限异常；退到系统设置或留在当前页面提示。不会自动写无障碍设置；不开启时保留宿主图标路由。 |
| 操作页比例错误 | APK：普通业务 VD 使用实际主屏逻辑分辨率和密度，主屏镜像显示整个同实例界面；仪表的有效区、等比 FIT/CROP 独立计算。原生 Meter 仍使用仪表专用布局。 |
| 直立侧边、浅色突兀 | 仪表：按五张原厂玻璃遮罩的 alpha/原位置取轮廓，连续几何软边替代全高直条与角部重复叠加；普通原生 Image2D/PNG，不加自定义 shader。原厂 state2 直接切换深浅原色，运行中可变。 |
| kW 在数字下方 | 仪表：全幅功率数字右对齐，单位移到右侧，保留原始数字、负号、单位切换和数据绑定。中心窗/停止后的原厂数字布局不强改。 |
| 续航条少底板贴图 | 仪表：移除隐藏整个 Prefab_Cluster_Board 父节点的私有覆盖，恢复原厂 Fashion/Classic 底板和主题控制，不重绘续航数据。 |
| 按钮连在一起 | APK：自定义背景取代系统带内缩的按钮背景后，没有外边距；补纵向上下各8dp、横向12dp，应用列表收藏/选择分离，标签加高避免长文字挤压。 |

全幅可读内框为 **(256,144,1408,368)**；大中心窗外框768×432、内框720×384。传输仍1920×720。曲边/软边不是可读区域；主屏应用尺寸不再反过来取这些内框尺寸。

## 升级后重点操作

1. 升级本次配套仪表 App，覆盖安装 APK；已匹配的 MCU/OS 不为本轮改动重复刷写。
2. 普通应用直接开始，点原应用图标应进入同实例操作页，比例保持主屏；Home、其他应用、再点图标，仪表继续显示。停止后保留业务任务。
3. 定制高德保持原生主界面/Meter双入口，持续显示、停止再投各做一轮；冷启动的官方高德和其他转发入口应不需第二次点击。
4. 无障碍入口缺失应显示提示，不能使 Dashcast 退出；不需要通过清数据获得权限。
5. 仪表全幅切深浅，查看曲边、功率数字/右侧单位、续航条底板及里程；切中心窗、停止确认原厂状态恢复。

建议先关闭裁剪确认全部应用提示都可见；裁剪开启仅裁仪表输出，可能裁掉上下/侧边提示，不拉伸主屏操作界面。地图自身昼夜仍由地图设置管理。

## 质量边界

构建/单测、旧新实际 Android29 静态GL与冷转发反例、真实图标/触摸/任务归还、保存原生资源/ARM生命周期、桌面 GLES 像素及软件 AVC/接收合约分开记录。不把这些当成车机 Qualcomm 编码器、Kanzi/IVA-HD 或全部告警实车通过。完整系统输入法、应用安全窗口/禁止副屏、原应用自身业务限制仍可能存在；不修改原应用、原账号或系统全局 ActivityController。

真实媒体断档、任务身份变化、失联或原生恢复错误仍停止/保护。保留两秒 PTS、四秒新IDR、五秒滚动恢复；静止重绘必须在当前任务归属有效且有当前来源帧后进行，不能用新提交时间掩盖跨源旧图。没有累计时长、视频授权、软件停车或正常切模式拔线限制。
