| 模式 | 1920×1080源示例 | 使用边界 |
|---|---|---|
| fit | 完整源→426×240、居中x107 | 保比例、完整画面，OEM留边外观待实显 |
| crop | 源(0,180)1920×720→640×240 | 保比例填满，舍弃上下边缘 |
| region | 10/15/95/90%选(192,162)1632×810→483×240、x78 | 用户手动地图区域，不自动识别导航窗口 |
| stretch | 完整源→640×240 | 旧拉伸供回归对照 |

region四边0～100整数、每维至少5%跨度；按实际主屏尺寸计算，拒绝空矩形、超界和任意shell输入。帧输入/输出矩形与仪表窗口是两种坐标，不把源裁剪当移动QNX窗口。

开发/桌面证据不是实车验收，见[状态](VALIDATION.md)。按[停稳顺序](USAGE.md)先20～30秒逐模式比较，确认停止/窗口退出后再换模式；保持原Host拔线保护。新几何通过后补600/1800秒自然到时、同一NCM三次、后台/通知停止及异常退出。

下一项依赖是动态HMI/Screen安全集成：确定各主题/状态父变换、告警窗口优先级与让位/退出策略，完成停稳台架实显，再讨论更高清成对协议。不能直接扩大中心窗口或只调APK编码分辨率。
