# 1.12.1 内圈边界修订

全幅开口改按仪表内圈形状：上沿及左右圆滑收拢，下沿接续航底板。两侧装饰圈仍按现有全幅策略隐藏，小窗保留原主题装饰。不能把玻璃外缘当视频开口，也不能只换一个圆角矩形。

源画面为1280×336，完整落在曲边内部；1920×720仍是编码传输尺寸。外侧沿用32×16低频画面填充及原主题底色，24设计像素向内羽化，不把高清字形拉伸到边缘。两主题共用alpha曲线、使用各自原主题颜色。地图自身昼夜模式仍由地图管理。

曲线依据用户内圈照片的形状重建，并锚定已检查的原生顶部线y124与续航底板y553。它是设计拟合，未执行真实Kanzi，不宣称照片透视标定或全部物理边缘逐像素精确。主屏托管/图标、地图入口、按名接入、角色切换、停止/失联保护和普通车模让位承接1.12.0。

需配套安装APK与RWV9仪表App；完整包包含未改原MCU，参考OS/Boot、角色与媒体链不改。已装匹配参考OS者只需升级仪表App和APK，保留应用数据及ADB身份。第一次覆盖前停止旧会话。

公开组件重现：

```bash
python tools/build_inner_ring_components.py --hmi /path/to/original-hmi --kzb /path/to/original-kzb --toc /path/to/original-toc --scene /path/to/original-scene --receiver /path/to/reference-receiver --output /new/output
```

只接受精确哈希输入并拒绝覆盖；输出四组件不是可刷FULL。源码不含照片、原固件、密钥或原始日志。真实车机GPU、Kanzi跨资源及最终边缘观感仍需本版实车反馈，不将离线ARM/GLES/编码夹具称为实车通过。
