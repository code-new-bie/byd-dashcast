# 1.18.0 应用操作窗口

从“应用”选择应用，在“投屏”点击开始，立即进入操作窗口。即使应用还没启动，也在窗口内完成打开和接管；失败可原位重试或返回首页。应用运行于一个任务，两端共享状态、账号和导航，不复制应用数据。

仪表只有全屏、小窗两个画面档。手动选择的应用按对应窗口比例布局：全屏高清源3392×912、密度320，小窗2304×1296、密度480；分别对应既有1696×456、768×432接收窗口。应用先高清渲染，仪表和主屏各从同一原始画面生成；主屏不解码或放大低清的仪表视频。密度与采样倍率配套，避免文字和按钮随分辨率提高而缩小。

主屏使用同一个操作页，按本次源比例，在实际可用空间内最大等比显示。操作窗口不会拉伸或裁切，窗口外用本应用主题色留白。全屏源比例较宽时，上下留白属于比例适配。打开、离开、重新挂接或弹出输入法，不再把业务屏尺寸改回主屏尺寸。系统状态栏、导航栏和输入法仍由车机管理。

投屏中可回桌面、打开其他应用；仪表继续显示所选应用。点击所选应用的原图标回到同一任务的操作窗口。窗口右上角“投屏控制”可返回首页、更换应用、停止或继续操作。停止只结束投屏，将原任务归还主屏，保留应用及导航状态；更换应用先等待原会话清理完成，一次只有一个应用投屏。未知清理状态的保护不被绕过。

管理页收敛为“投屏／应用／设置”。连接与应用接入是两个独立开关；帮助、日志导出和技术详情放入设置。全屏／小窗的变更在下一会话生效。更多比例选项仅用于其他接入方式，不影响本次自动适配的操作窗口。

定制地图原按钮、服务提供的左下角备用按钮，以及按名称`fission_dashcast_meter`接入，仍走既有原生入口；它们不被手动操作窗口强制转换。手动选择高德或定制高德时，使用上述同任务操作窗口。

本版仪表固件与1.17.0逐字节相同：用户四张背景、显示曲线、接收器、HMI、原MCU、参考OS和Boot均保持。已刷1.17.0仪表包只需覆盖安装APK；完整配套交付仍包含仪表ZIP。APK延续原包名与签名，覆盖安装保留数据。

已执行的Android模拟器检查与实车检查分开记录。超采样不会生成第三方应用自身缺失的素材细节，也不能消除应用固定布局、受保护内容或车机GPU性能限制。本版不将模拟器吞吐当作实车帧率；USB、硬件编码和仪表动态观感仍应通过对应车辆回归确认。
