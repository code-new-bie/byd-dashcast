# APK 1.21.0：去掉首次弹窗、开机启动、主题跟随系统、地图原按钮可用

应用 1.21.0 / code73，配套仪表仍是 1.19.3，不用重刷仪表。签名不变，覆盖安装即可。

## 第一次投屏不再弹确认框

以前第一次投屏会遇到两个确认：

- **本应用的“开始前的准备”**：只在全新安装时出现，要求确认已装配套仪表包。现在去掉了这一步，直接开始；需要说明时可以在“设置 → 帮助与反馈 → 连接与首次使用”里查看。
- **系统的“允许访问 USB 设备”**：仪表每次切换到投屏模式都会重新枚举 USB 设备，Android 的 USB 访问授权跟着设备走，所以每次开机后的第一次投屏都会再弹一次。车机系统的 shell 有授予 USB 权限的系统权限（`MANAGE_USB`），现在由本应用通过已授权的调试连接，直接给自己授予仪表这一个设备的访问权限，系统弹窗就不再出现。授权失败时仍回到原来的系统弹窗。

剩下唯一的系统询问是第一次使用时的“允许 USB 调试”，勾选“始终允许”后不会再出现。这是系统对调试连接的保护，应用无法替用户确认。

## 开机启动

设置里新增“开机启动”开关，默认关闭。开启后，车机开机时自动恢复上次开着的“仪表投屏连接”和“应用内投屏接入”，不打开界面，也不自动开始投屏。

车机默认禁止第三方应用自启动。开启后还需要在原车的自启动管理（`com.byd.appstartmanagement`）中允许本应用，设置里有“前往自启动管理”按钮。

## 深浅色跟随系统

“界面颜色”改为三档：跟随系统（默认）、深色、浅色。跟随系统时，车机切换深色或浅色，本应用当场跟着切换，不需要重启。车机把自己的深浅设置换算到 Android 的夜间模式，本应用读取的就是这一位。

## 定制地图自带的仪表投屏按钮

**为什么以前没反应**：地图的这个按钮并不直接打开它的仪表界面。它只给车辆发一条“切换仪表导航类型”的指令，然后等原车仪表回报新状态，收到回报后才打开仪表界面。我们的仪表不处理这条信号，地图永远等不到回报，所以点了没反应。

**现在的做法**：
- 本应用通过无障碍服务识别这个按钮的点击，由本应用打开或停止地图的仪表界面投屏：点一次投到仪表，再点一次停止；正在投其他应用时，点它会换成地图。
- 开启“应用内投屏接入”时，会通过已授权的调试连接自动打开本应用的无障碍服务。已开启的其他无障碍服务保持不变。

本应用自己画在地图左下角的备用按钮去掉了，用来显示它的悬浮窗权限也一并去掉。

地图按钮本身是否出现，仍由地图决定：要求地图服务启动时已经存在接入屏幕，并且车辆报告的导航类型大于 0。所以要先开接入，再从头启动地图。

## 验证范围

- 单元测试 598 项通过，lint 0 错误。
- 在 Android 10 模拟器上验证了以下内容：
  - 三档主题，以及系统切换深浅时界面就地重绘（进程不重启）；
  - 开机启动：重启后恢复了接入开关；
  - shell 侧打开无障碍服务：只追加本服务，重复运行不重复添加，系统随即绑定服务；
  - 点击仿造的地图按钮后，App 记录到点击。
- USB 授权调用的两个系统接口，签名按车机 framework 核对过；在模拟器上能调用到系统 USB 服务，但模拟器没有 USB 设备，没法完成实际授权。

以上都还没有在本版实车上验证。
