# 1.25.0：投屏期间切换仪表样式

APK **1.25.0/code80** 与仪表 **1.25.0/RWVH** 必须一起更新。覆盖安装保留原有应用设置和 ADB 身份。

## 修改

全屏投屏时切换整套仪表样式，原厂主题和投屏状态都设置速度、功率数字及单位的几何；相同投屏状态反复写入不会重新应用，形成混合布局。原回执只检查蒙版，未发现数字错位。

- 四个局部变换和速度对齐这五项属性，从原厂主题组及 DCFull 迁到专用 `DCGeometry` 组。全屏选择 Full，其他模式选择节点当前的原厂样式；停止后采用最后选择的样式。
- 原厂转场中另有十条相关动画规则，同步迁入新组的原厂状态分支；保留其余动画、绑定、状态组和资源。
- 渲染线程每帧解析当前 RootPage/Content/Cluster，不缓存节点指针；只写本地私有 `DCGaugeLayout`。全屏读回四个实际 SRT2D 和速度对齐。缺失节点、错误父级、类型错误、非有限浮点或几何不符均不报告匹配。原厂/小窗保留原几何动画，不将其动画中间值判错。
- APK 对活动期间的合法布局待确认提供最多 1000 ms 的同步窗口，不重置起点、不续租掩盖不匹配；归属、进程、能力、模式及撤销错误仍立即失败。超时走原清理流程。
- 接收端配对能力改为 RWVH，防止新 APK 把旧蒙版确认误当几何确认。视频协议和窗口、USB 脚本、背景曲线及分辨率保持现有实现。

## 仪表修改范围

完整包中仅三项 app.sv 成员变化：

| 成员 | 改动 |
|---|---|
| `base/app/rc_hmi/rc_hmi.exe` | 渲染调用和几何检查；使用现有前置页预留槽，不增加 LOAD、不改变 ELF/PHDR 结构，保留完整 Alpha 槽 |
| `base/app/rc_hmi/bic_byd_stha.kzb` | 几何状态与动画迁移、私有属性注册；背景图片、其他资源不变 |
| `base/app/dip-instrument/instrument-receiver` | 配对能力常量 |

OS、MCU、三个版本文件及其他成员的字节、属主、权限和顺序按上一完整包保留。

## 验证范围

- 627 项 Android 单元测试通过，lint 0 错误；覆盖同步恢复、固定超时、第二次同步、能力不匹配和归属/模式/进程变化及撤销。
- 82 个 Unicorn 用例执行新生成的实际 Thumb，以及原 HMI 的整数 getter/父节点 getter 指令；覆盖各变换字段、NaN/Inf、浮点容差、缺失节点/错误父级、寄存器与栈、回执包装、同状态不重施加下的切主题和停止恢复。
- 树查找、属性存储、状态应用使用受控替身；没有执行完整 Kanzi、QNX Screen 或实车，不能当作物理显示验收。
- 从原件重建组件、核对固定哈希，完整包独立回读并检查上述三成员变化。

重点实车检查：全屏 Fashion→Classic→Fashion、快速连续切换、小窗/全屏切换、停止/换应用/拔线后的最新主题恢复，以及数字/单位、里程/续航、告警和深浅模式。

## 使用

1. 刷入本版完整仪表包，覆盖安装本版 APK；两端都要更新。
2. 按平常方式开始全屏地图或其他应用投屏。
3. 保持投屏切换整套仪表样式，反复切换；数字及单位位置应保持，视频继续。
4. 在新样式下停止，应恢复最后选择的原厂样式；再测小窗和深浅切换。

构建入口：[build_instrument_components.py](../tools/build_instrument_components.py)。使用上一 RWVG 三组件的指令回归入口：[test_theme_geometry.py](../tools/test_theme_geometry.py)。
