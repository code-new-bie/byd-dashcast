# 1.19.0：投屏页内操作窗口

操作窗口移到“投屏”标签页。顶部保留投屏、应用、设置，应用画面用满页内可用宽度并保持比例；开始、停止、更换应用、应用返回、仪表连接和全屏/小窗放在窗口下方。移除独立操作页和右上控制菜单，设置页不再重复提供全屏/小窗。

安装时覆盖APK，保留数据与ADB授权。配套完整仪表包和1.18.0/1.17.0逐字节相同，包含原MCU、参考OS及Boot；已经匹配这两版的仪表无需重复升级。

1. 在应用页找到目标，点“选择并开始”。窗口会在投屏页内等待、打开应用并显示画面；应用已运行时接管已有任务。
2. 全屏与小窗按各自比例等比显示。全屏比例约3.72∶1，小窗16∶9，主屏剩余空间不会通过拉伸或裁图填满。采集仍使用配套密度的高清源。
3. 切到应用/设置或返回桌面，仪表继续显示；回投屏页或点原应用图标，继续操作同一任务。
4. 浏览应用列表不会停止当前投屏；确认另一应用后先结束旧会话，再开始新会话，一次只有一个拥有者。
5. 全屏/小窗只在投屏页设置，运行中修改提示下次使用；本次任务和源尺寸不变。主屏输入法及窗口大小变化只调整操作窗口。
6. 停止会归还原任务，保留导航/应用状态；关闭仪表连接则先清理，再请求恢复U盘，无需拔线。设置中的应用内接入开关与之独立。

实际Android模拟器回归范围与构建结果见发布记录；目标车机硬编码、USB、仪表实际合成与全部第三方应用兼容性需以车辆反馈为准。没有新增停车、拔线或会话时长限制，没有修改仪表背景/曲线或MCU。
