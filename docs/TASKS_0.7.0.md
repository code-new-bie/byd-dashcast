# 0.7.0 高清任务与剩余门禁

## 已完成的源码目标

- 持续投屏请求硬件 H.264 Baseline 1920×720、6 Mbps、30 FPS。
- DCV1 START/AVC 尺寸契约与仪表接收器的高清范围同步。
- 在发送端按编码 PTS 限流，避免高帧率编码器产生无限积压；同步 ACK 继续提供背压。
- 保持用户态 USB NCM、TCP 31707、无视频授权、原停止/清理和 Host 恢复边界。
- 仪表端只保留高清接收器适配；MCU、参考 OS、USB 角色脚本和原媒体/清理分发不改。

## 已通过的离线门禁

桌面生成的真实 Baseline H.264、Java DCV1 封装、PTS门控、ARM解析、ACK/STOP清理、Android单测、APK构建和成品静态审计通过。它们不等于 Android MediaCodec、QNX IVA-HD/Screen 或车辆真实显示通过。

## 实车门禁

1. 停稳或可恢复台架安装匹配的0.7.0 APK和仪表App。
2. 先短时确认硬件编码器实际输出1920×720并观察仪表动态画面。
3. 读取 `FRAME_RATE_GATE`，记录输入/输出PTS；另外测量仪表实际显示帧率，不能仅用ACK代替。
4. 逐步回归20～30秒、600秒、1800秒、后台、自然结束、异常退出、重复使用和视频后Host/U盘恢复。
5. 动态车速/挡位/告警/导航层级未完成安全隔离前禁止道路使用。
