# 1.12.2 全内圈清晰视频

1.12.1候选错误地将1280×336安全参考框当成高清边界，其余内圈填了模糊画面。用户从预览指出该问题；该候选撤回推荐，没有推送或发布Release。离线构建通过不等于产品视觉正确。

本版1632×440清晰源覆盖整个内圈开口，安全参考框仅作应用布局参考，不参与裁切。内圈内部保持清晰，仅沿原曲线向内24设计像素渐变，原主题颜色/全幅装饰圈隐藏、小窗策略保持。1920×720是传输尺寸，视频源矩形是承载范围，真实可见开口由内圈曲线定义。

本版没有非线性拉伸，也没有修改任意第三方应用自己的按钮布局。源画面角落在异形开口外会被遮住；具体地图角落控件的适配必须按地图版本确认，不能用缩成矩形和模糊填充假装已解决。主屏业务布局保持原可用区，与仪表几何独立。

配套APK1.12.2/code53与RWVA仪表App，原MCU/参考OS/Boot/角色/媒体链保持。原1.12功能与普通车模/道路让位承接；本版没有新的实车/Kanzi结论。

```bash
python tools/build_sharp_inner_components.py --hmi /path/to/original-hmi --kzb /path/to/original-kzb --toc /path/to/original-toc --scene /path/to/original-scene --receiver /path/to/reference-receiver --output /new/output
```

输出是哈希固定的四组件，不是可刷FULL；生成需要已有Pillow/原生工具依赖，纯几何和CI合同测试不要求图像库。禁止覆盖输出。普通应用自身副屏/安全窗口限制保持既有范围。
