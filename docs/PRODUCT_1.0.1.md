# Dashcast 1.0.1：健康会话持续投屏

1.0.1/code34取消1.0.0的人为累计会话限制。产品入口不按两小时、累计帧数或累计传输字节数停止，也不在后台定时重连。保持当前会话，直至用户停止、真实断连或异常。

## 使用及匹配

安装1.0.1 APK，并升级本次匹配仪表App、正常重启。不能只更新APK后沿用1.0.0接收器/HMI：DCV1/3与RWN2能力需要两端匹配，旧端会在开始前拒绝，避免静默退回有限模式。MCU、参考OS、Boot/KZB/原生前景及1.0 USB角色脚本内容不变；完整包可能重刷这些原件。

仍从首页选择导航或应用→开始投屏，通知或页面均可停止。USB切换继续先停止、确认原生恢复/媒体与采集退出、ALT0与接口释放，再走原厂导航命令；无需为常规操作预先拔线。未知清理仍阻断强切，不把设备消失当仪表Host成功回执。

## 去掉和保留的边界

| 去掉的产品总量上限 | 保留的异常/资源保护 |
|---|---|
| 7200秒采集结束、仪表121分钟总期限 | 15秒新鲜心跳、单次USB/ADB/清理超时 |
| 240000视频帧、500000采集帧 | 单帧2MiB、AVC/SPS/首帧门禁、有界队列 |
| 累计8GiB采集流量 | 原生五秒失联恢复租约、PID/代次/所属校验 |

duration=0只表示受控产品持续采集；工程页短探针仍有限，不代表正常使用仍有总时限。序号/心跳和线上毫秒时间戳按uint32模递增，完整源时间与累计统计使用64位，避免用序号溢出或统计乘法溢出引入新的截止。服务持锁按活跃所属短租续期，停止即取消续期并释放。

## 本次证据与范围

根374 JVM/53套、39实际ARM/Thumb指令回归、30帧高清/软件MD5/OEM入口契约及成品独立审计。覆盖同一连接250001帧、采集超过500000帧/累计8GiB、假时钟12小时续租、线序号/PTS/心跳回绕和主动STOP。API/媒体/USB/Screen是替身或静态核对，**不是实车运行12小时或物理全屏/全部告警/道路安全认证**。

MCU不改，USB/视频/独立副屏/背景已通过的车辆版本基线保持。新全尺寸真实合成、全部动态告警、目标硬件带线切换和长时表现仍要由现场证据确认；取消人为上限不等于承诺任意时长零故障。首次匹配升级在停稳场景检查原生信息、停止/恢复，再正常使用；关键前景异常则停止并按保留旧配套回退，不强杀系统服务。
