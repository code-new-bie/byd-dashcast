# 1.7.0 双端布局与可读性

APK code43，配套RWV4仪表App。不是给旧1.4固件换个版本名。

## 改动与原因

| 问题 | 原因与处理 |
|---|---|
| 原生道路/后视车与地图互相盖住 | 原来只隐藏背景，ADAS模板仍按整屏坐标显示。给原2D模板加临时模式组：静态透视路不参与投屏合成，ACC/车道/车模/LDW图形进入独立紧凑区域；Small模板保留原根/路径/主题组，追加模式组。不是缩窄地图到右栏。 |
| 原生车与地图箭头像两个定位 | 原生图形和地图定位分开呈现，原生状态仍是ADAS，不把它冒充GPS，也不改地图定位数据。原接管文字与车门/安全提示不隐藏。 |
| 全幅底部浅色对比不足 | 旧渐变延伸至y624，续航/OK等所在y580仍有地图透过。新有效区(96,144,1728,384)，y572及以下为原厂主题不透明底板；地图界面在扣除保护区后排版，不先按整屏再裁。 |
| 小窗字号过小 | 1200×640源在仪表缩为720×384，160dpi的16sp只有9.6物理像素。中心VD单独用240dpi，变为14.4px；全幅1728×384源按有效内容1:1输出。未修改主屏或系统全局密度。 |
| 边缘条纹、矩形与黑底感 | 承接1.6仅外填充柔化；原生四边渐变按新内框配套调整，信息衬底及ADAS软边使用原厂蓝灰深浅画刷，不增加新材质/GL shader。ADAS底板10级羽化。未声称复刻原参考图每条弧面高光。 |
| 安全带落在转向卡上 | 三种原生Indicator模板只在全幅把原40×48安全带灯移到左下信息轨(360,584)；原显隐/数据/节点路径保持，中心与停止不加覆盖。其他真实告警保持原厂优先。 |
| 车机按键/24℃等混入地图 | 1.5/1.6已取消主屏镜像并采用匹配原车Meter入口；本版保留该机制。原Meter根XML只有独立地图/NavHost，不靠裁掉固定像素假装清理所有导航应用自绘控件。 |

原生状态0是空修改集：停止、所属租约到期或失联后恢复当时的原厂状态，不回放过期车速/车道数据。原安全状态资源、数据绑定、接管字体和独立3D工程原字节保留。当前视觉调整针对已分析的2D模板；没有宣称所有3D/其他车型场景均适配。

## 升级与使用

使用同目录配套APK和完整仪表包；至少更新其中App及同签名APK，保留应用数据。MCU/参考OS/Boot没有新补丁，完整包仍含未改原件。RWV4会拒绝旧RWV3组合，不强行绕过能力门禁。

原车导航需核验版本220102029；其他应用必须支持同用户多实例。正常一键开始/停止；布局设置开启为全幅、关闭为大中心窗，停止后切布局。期间仍由原导航图标进入车机界面。不新增累计时限、停车勾选、手动拔线或取仪表日志前提；Host/NCM流程及恢复门禁保持。

更新后集中看新增部分：大小窗两种主题下地图提示/字号、原生车模是否与定位分离、底部/里程和安全带可读性；停止/意外断线后原厂布局恢复。主题在运行中切换时观察融合层跟随，地图昼夜由导航设置控制。出现真实故障/接管信息时原厂提示可覆盖地图，这是优先级，不应隐藏。

## 交付证据边界

代码/原生指令执行、保存资源精确逆恢复、真实桌面GLES像素、Java/真实AVC/ARM协议和独立APK构建是离线证据。它们不等于原厂Kanzi引擎、目标Android/QNX GPU、真实30FPS、所有ADAS状态和导航业务均已验收。不能把此包称为已经实车认证的最终视觉成品。
