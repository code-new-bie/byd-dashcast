# 1.14.4 精简旧开发页面

本版删除旧开发页面及其专属 RTP/TS 发送路径。此前入口仍能从“帮助 → 更多支持选项 → 开发工具”进入，并非代码已经删除；旧 UDP 接收端口也没有在配套仪表中配置。

现在帮助页直接提供“查看技术详情”，继续保留重新连接和导出日志。旧工具的拔线、30分钟及台架提示随页面一起移除，避免与正式用法混淆。旧采集设置UI、USB网卡RTP发送、RTP打包和MPEG-TS封装不再编入APK；对应旧测试随功能退役，Git历史保留原实现。

正式投屏仍使用原来的USB/NCM、DCV1/H.264和RWVF合成通道，ADB身份、应用偏好、填满/完整显示、无障碍原图标、地图及命名屏接入、单会话和停止恢复保持。诊断所需的技术详情与日志继续可用；共用的编码和网络模块不因旧入口删除而移除。

APK为1.14.4/code63，覆盖安装并保留数据。配套仪表仍为1.14.3/RWVF，**已安装者无需重复刷仪表**；完整交付中的仪表ZIP保留原文件名和全部字节，MCU、参考OS与Boot不变。首次安装仍按[使用说明](USAGE.md)准备配套仪表。

重点确认帮助页没有开发工具或旧RTP入口、技术详情能打开、日志能导出；再正常开始和停止一次投屏。这里没有改变仪表显示代码，原背景、真实启动和动态场景的未完成现场确认范围继续见[1.14.3](PRODUCT_1.14.3.md)，不将本次清理作为这些问题已获实车验收的证据。
