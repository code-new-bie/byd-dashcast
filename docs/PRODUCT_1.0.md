# 1.0 产品候选：实际 APK 与配套仪表 App

2026-10-21，versionCode33。替代工程 Demo 默认入口，不再要求每次跑五秒探针或填时长。正常导航不以停车勾选为启动条件；这不代表已经取得道路安全认证。历史版本文档的限制与状态只代表当时版本。

## 用户流程

1. 安装本次匹配仪表 App/同签名 APK，正常重启仪表；FULL 含原 MCU/参考 OS/引导且可能重写这些未改组件，不混用旧目录。源码克隆本身不提供固件或签名身份。
2. 保持车机和仪表 USB 数据线连接。首次设置确认已安装配套固件，再允许本机 ADB 调试；原有 ADB 身份不更换，视频无激活/付费授权。
3. 应用中心选择高德分身等导航应用，可搜索、收藏和设为默认。首页“开始导航投屏”自动准备 NCM，首次出现系统 USB 弹窗时允许访问，随后开始。
4. 可切换车机其他应用；仪表继续显示所选独立副屏应用。没有应用兼容性时明确失败，绝不悄悄回退镜像整个主屏。
5. “停止投屏”恢复背景并退出当前媒体、采集和 USB 占用。“恢复 U 盘模式”先完成上述清理，再确认 ALT0/接口释放，单次 OEM 文字请求，仪表 soft-link-down 后退出私有协议栈。**不要求手动拔掉车机到仪表的数据线**。
6. NCM 已连接时重复请求 NCM 不会重置连接或打断投屏。Host 逻辑断开不是仪表 Host 成功回执，界面不会伪报成功；结果仍以仪表提示/实际 U 盘识别为准。

应用选择/设置请在不分心的安全场景完成；驾驶中只使用导航，不观看娱乐视频。软件未接入可信车速/挡位判定，不伪造“已停车”或自动驾驶模式。任何关键信息异常，立即停止投屏。

## 四个实际页面

首页：所选应用、真实会话与连接状态、一键开始/停止、连接仪表/恢复 U 盘。应用中心：搜索、收藏、默认目标，导航类别优先。设置：保持比例/中心裁剪、全尺寸原生前景下层/兼容小窗、日间浅色/夜间深色，配置下一会话生效。诊断：ADB 授权、有界详情、一键日志导出到下载目录，历史工程台隐藏在高级入口。

Kotlin 实现产品 Activity、协调器、应用目录、配置、角色工作流与持续合成控制；保留已打通 Java 编码/DCV1/NCM/shell ABI。不是将 Java 改后缀，也不是宣称全项目已迁移。AGP9.3 内置 Kotlin，依赖工具链不更换。

## 持续合成与退出

默认实际 1920×720 视频位于原生窗口下方，HMI 只处理已检查背景，原生前景路径不改；小窗为显式兼容选项。相同健康连接每秒续租原生五秒期限，HMI 校验 nonce/PID/epoch/序号/新鲜度。停止先恢复背景，再媒体 STOP、采集 EXIT 和 USB ALT0/接口释放；缺失任何确认进入隔离，不自动连发或强切。

这是单一最长两小时连接，不是循环五秒重连。每帧2MiB、240000帧、累计8GiB与121分钟接收上限仍有界，失联最多五秒恢复原生背景；这些限制不是内存预分配。旧工程一次五秒 START 不会因重复请求续期，只有新匹配能力 `RWN1` 允许同所属 RENEW。旧仪表不满足能力时，在媒体 START 前拒绝全尺寸产品会话。

参考 OS、国内 MCU、MLO/IFS/Boot、KZB 和前景业务不改。仪表 App 仅 receiver、HMI 背景桥、USB角色等待脚本三项相对0.10.0改动，alpha配置沿用。
