# 1.17.0 背景、完整画面与地图按钮

请配套更新本版APK与完整仪表包，覆盖安装并保留应用数据。原MCU、参考OS、Boot、HMI程序及视频接收器保持不变。

本次修正的不是背景原图，而是仪表图片节点的内容缩放。四个自有节点明确使用铺满，8×3底色覆盖完整节点，1920×720蒙版使用全部纹理范围。四张用户原图的RGB、透明度、曲线和渐变保持；原生信息仍在视频上方，停止恢复原厂界面。

首次升级将旧的默认裁边设置切换为“完整显示”，后续手动选择仍保存。仪表完整画面放在背景真正透明的区域内，避免顶部信息、四角或左右按钮被曲线遮住。主屏业务尺寸和操作界面不改。两屏比例不同时，完整画面等比显示，外围使用背景衔接；这不会把车机主界面的全部内容强行拉伸成仪表比例。定制地图继续使用已验证的独立仪表界面。

开启应用页的“应用接入”，等接入就绪后打开定制高德。原按钮没有显示时，左下角提供“仪表投屏/结束投屏”按钮，点击使用同一投屏控制流程，一次仍只能投一个应用。按钮由接入服务管理，只在主屏定制高德前台时显示，离开地图或关闭接入后移除，不抢主屏输入焦点。备用按钮不再要求先开启无障碍；已有原按钮和无障碍点击监听仍保留。

备用按钮需要本应用的悬浮显示权限。开启接入时，已授权的车机ADB仅为本应用申请该权限，不修改其他应用权限。若设备拒绝，接入日志会记录结果；这不影响普通应用投屏或屏名接入。按屏幕名发送仍使用`fission_dashcast_meter`。

重点回归：全屏及小窗的深浅主题和四边；导航转向卡、时钟、缩放等控件完整；主屏通过原图标打开、切其他应用和返回；无障碍关闭时的左下角按钮显示、实际点击、停止及重复开始；原按钮存在时不重复显示；离开地图及关闭接入后的移除。

本版使用保存KZB节点的真实ARM布局函数、实际混合因子和GLES读回来验证背景，不再假设图片会自动铺满。完整QNX/Kanzi及实车验收仍依赖本版实测反馈。
