# 1.13.0 产品界面与文案梳理

执行者 Codex，2026-10-28。承接1.12.6/code57/RWVE与B01～25。此次针对应用设置、信息层级和常用操作，不改仪表、视频映射、USB角色协议、图标接管/触控/导航任务及未知清理隔离策略。

## 发现的问题与处理

| 原界面 | 问题 | 新界面 |
|---|---|---|
| 首页并列开始、停止、打开操作画面、地图、按屏幕名等入口 | 同级操作过多，未投屏也展示无效入口 | 开始/停止固定底部、随状态改变，短屏与滚动时始终可见；有可操作画面时才展示打开入口 |
| “导航仪表布局”开关及长段像素/固件说明 | 难以知道开关对应全屏还是小窗 | 明确的全屏/小窗单选，几何和配对字不在日常设置展示 |
| “裁剪填充”常驻，与已匹配比例时效果重复 | 用户难以判断必要性 | 更多画面选项中的完整显示/填满区域，说明仅比例不一致时生效；保留原偏好和行为 |
| 日间浅色、仪表融合、地图昼夜混在一起 | 容易误以为一个开关能改变两端主题 | 本应用深/浅单选；一句话说明仪表跟随自身、地图在地图中设置 |
| 首页长期展示NCM/Host、ADB、固件能力字、托管/镜像说明 | 技术实现压过操作目的 | “仪表投屏连接”“车机已连接”；系统“允许USB调试”名称只出现在需要用户识别的步骤 |
| 多处“同实例、独立入口、路由、清理隔离” | 术语多，旧术语甚至与当前实现不符 | 用“点击原应用图标继续操作”“上次投屏尚未完全结束”等行动说明；原始证据留日志 |
| 未知错误直接显示异常名与消息 | 没有可执行建议，可能泄露内部路径 | 简短结果+重试/检查线/允许系统弹窗/导出日志/必要重启；不虚报恢复成功 |
| 固定横排按钮及过大的顶部四导航 | 窄屏、大字号可能拥挤 | 车机宽屏左导航、内容两列；窄屏顶部导航、列表操作换行，明确外部间隔 |
| 应用能力刷新、包名搜索、收藏混合 | 研发词汇与日常寻找应用混杂 | 刷新列表、搜索应用、全部/常用；仍支持包名检索，预检不宣称实车已兼容 |
| 地图/按屏幕名与普通开始同级 | 有用途但不是所有应用的必经步骤 | 应用→其他投屏方式，保留地图快捷开关及应用内投屏屏幕名复制 |
| 每次非地图启动再次弹出长确认 | 重复打断已选择的操作 | 首次连接说明和帮助集中说明；开始直接进入既有受保护启动流程 |
| 日志、技术详情和工程实验同级 | 排障入口不清楚 | 帮助页一键导出；技术详情和开发工具放在更多支持选项 |

## 交互及迁移

四页为投屏、应用、设置、帮助。首页只解释当前状态，主要按钮根据实际会话/当前操作变化；启动中可取消，运行中可停止，停止中和未知清理仍阻止重新启动。记录操作类型仅服务于界面，不修改恢复/串行化/权限/清理判断。U盘恢复缺直接回执时仍要求看仪表提示，不因开关关闭显示成功。

原`dashcast.product.v1`所有键、原ADB身份、收藏、目标应用、深浅/裁剪/全屏偏好保持，不清数据。画面设置下次投屏生效，不重启正在运行的地图。应用内投屏、地图按钮、meterDisplay与同任务图标接管均保留；用户无须理解这些接口名。设置项没有新增付费/授权/时限或停车门槛。

APK版本1.13.0/code58，配对仍RWVE；仪表整包逐字节沿用1.12.6，已刷该包者仅覆盖安装APK。严格两文件交付约定保持，完整包保留原MCU。审计/截图另置结果目录。UI截图必须取自实际Android运行的新APK，并标明模拟器/夹具状态，不用网页重画冒充运行结果。

## 验证范围

新增呈现策略测试覆盖：首次设置/无应用、启动取消、导出中仍能停止、重复启动阻止、停止中阻止、未知清理保持阻止、断线进入既有恢复、USB缺失不等于U盘成功、未知错误不漏原始内容。复用全部现有会话/媒体/命名入口/图标逻辑回归。真实Android检查宽窄/深浅四页布局、字体与触摸区域、偏好保留、全屏/小窗及更多选项、其他投屏入口和日志导出。

本轮不关闭P31地图角落裁切、普通宽源主屏镜像比例及真实3D实例/目标硬件性能边界；没有以UI文案声称已修复这些问题。离线/模拟器结果与实车证据分别记录。
