## 当前0.7.9候选

源码、离线协议契约、Android构建和静态检查已通过。目标为硬件 AVC 1920×720/30 FPS；发送端先校验实际输出尺寸，并在结束时记录编码PTS/墙钟FPS，再按编码器 PTS选帧、将接受帧重定时为固定33,333微秒，让Surface无新缓冲时按同一间隔重复上一帧，并在同步DCV1写入前按单调时钟排程33,333,333纳秒；慢ACK迟到后下一 slot 从当前发送起点重锚定，避免追赶突发；`FRAME_PACER`额外记录最小/最大发送间隔和`burst_intervals`，用于现场识别局部突发。重复静态帧、发送端FPS统计和传输排程统计都不代表真实运动或远端显示帧率。

## 现场首测门禁

1. 使用匹配版本的应用和设备端接收器，先做短时动态画面。
2. 记录硬件编码器选择、输入/输出/丢帧和固定PTS间隔。
3. 单独确认远端真实画面、实际显示帧率、停止清理和恢复普通 USB Host。
4. 短测通过后再做重复使用、后台切换、长时和异常退出回归。

离线测试、ACK数量、窗口可见属性和CI绿灯都不能替代真实画面或道路安全验收。
