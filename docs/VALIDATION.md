## 每次提交都会运行的检查

CI（`.github/workflows/check.yml`）在每次推送时运行：

- 公开文件检查：清单与 `SOURCE_MANIFEST.json` 一致，没有固件、密钥、日志等内容；
- `tools/tests` 下的工具测试：只检查参数和拒绝错误输入，不需要固件；
- 便携背景控制器的 C 测试：用模拟的渲染接口，不是 QNX 交叉编译；
- Android 单元测试、debug 构建和 lint。

需要固件原件的组件重建、仪表 GPU/显示控制器/视频硬解，以及动态告警，都不在 CI 范围内。

## 历来只能在实车上确认的事项

- 仪表最终的画面合成（GPU 与显示控制器），包括遮罩边缘效果；
- 视频硬解码和长时间运行；
- 全部动态告警在投屏时的显示；
- USB 角色切换和数据线的电气兼容。

离线检查通过不等于实车通过。各版本的实车结论见[改动记录](../CHANGELOG.md)。
