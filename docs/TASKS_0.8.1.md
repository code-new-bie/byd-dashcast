# 0.8.1 视频显示修复

0.8.0现场报告无画面，本版需要配套更新APK和仪表App。

| 项目 | 结果 |
|---|---|
| START字段纠正 | 前两项是窗口x/y，不是编码宽高；恢复 `(640,240,640,240,30,0)` |
| 高清尺寸独立校验 | 原矩形/媒体函数保持，SPS宽高独立验证1920×720 |
| 远程副屏 | shell context创建前准备Looper，应用启动/输出有限超时，失败释放自有显示 |
| FPS | 偏差作为诊断，不提前终止有效视频；实际30FPS仍需测量 |
| 编码帧 | Surface输入限速、传输排程，保留完整P帧参考链 |
| 退出 | 非零EXIT仍是结束证据；缺EXIT或资源释放标记继续隔离 |

302项私有Java测试及最终APK构建/lint通过；公开测试排除32项旧凭据夹具。真实H.264/Java/DCV1/ARM解析、STOP清理和软件解码一致性通过。新增原ARM的Screen属性分发回归，明确旧坐标在屏外、新小窗在屏内；媒体、Screen、USB调用为替身，不代表实车画面通过。

仅改变仪表App接收器和APK；参考2 OS、国内原MCU、原HMI、USB模式脚本保持。FULL可能重写所携带的原组件，按现有可恢复升级入口操作。

现场先测试图10秒及二次播放，再主屏10秒、指定应用探针/投屏、停止退出和拔线Host/U盘。短时全通过再验证600/1800秒。动态告警隔离与跨屏应用兼容性、真实解码/显示和实际30FPS仍是独立未完成项。
