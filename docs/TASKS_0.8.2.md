# 0.8.2 高清接入修复与验证

承接已打通的USB模式、NCM/TCP/DCV1与历史小窗视频，不重新设计控制协议，不修改MCU、参考OS或原HMI。

## 已实现

1. 仪表SPS校验、媒体输入URI及H264 push配置统一1920×720，目标窗口保持原位置及640×240。
2. 采集helper在任何框架初始化前隔离Java stdout文字，视频直接写原始FD1。
3. 视频消费者失败时保留首错，停止所属会话并发送固定stdin STOP；在原有限预算内读取stderr和EXIT，缺释放或退出证据仍隔离。
4. 真实ARM配置包的新旧尺寸反例、真实JVM子进程FD分流、拒帧/非零退出/缺退出/持续输出超时回归，以及完整构建审计。

## 现场仍需验证

APK与仪表App同时更新，先停稳/台架测试图10秒并重复，再主屏10秒，最后指定应用探针/投屏。每种分别观察动态画面、停止后窗口退出及再次使用。成功后拔线切Host并检查普通U盘，再考虑延长时长。
