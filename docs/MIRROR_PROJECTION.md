# 1.9.0 同实例双端操作与原图标路由

本版主要改APK，不改DCV1、用户态NCM、MCU、参考OS或RWV5仪表布局。已刷配套1.8.0/RWV5仪表的车辆只覆盖APK并保留数据/ADB身份，不为APK功能重复刷仪表。完整配套仍为APK与原RWV5 FULL ZIP两个文件。

## 使用

1. 覆盖安装同签名APK，保留账号、应用数据与ADB身份。按已有方式连接仪表，允许正常ADB/USB访问。
2. 设置页可开启“Dashcast 投屏应用图标路由”无障碍服务；只在会话期间订阅当前投屏包的窗口变化，不读取页面文字或密码。不自动修改系统无障碍设置。宿主同时检查精确任务及当前包的系统启动信号，覆盖“点图标只给副屏焦点、主屏没有新任务”的情况；未开启无障碍时此只读路径仍工作。
3. 选择应用开始。普通应用的唯一业务任务托管在专用虚拟屏：仪表持续显示，主屏点原应用图标进入Dashcast操作镜像。两端同状态，不复制账号和数据。切其他应用、Home或离开镜像页不主动停止仪表。
4. 主屏镜像页按等比内容矩形映射触摸/多指和返回到目标display；黑边不映射到应用。Home、其他应用和系统多任务保持系统处理。“投屏控制”按钮离开镜像页，不是停止视频。
5. 主动停止后，普通业务任务归还车机，不force-stop或清除应用数据；原图标恢复原应用。换投另一个应用前必须先完整结束旧会话。
6. 定制高德com.byd.automap保留专用MeterActivity入口，主屏图标仍开原生主界面，不改成镜像。双入口表位于main/assets/native_projection_entries.json；这是渲染专项配置，不是允许投屏的应用白名单。官方高德及其他应用走通用托管路径。

## 结构及安全边界

```text
应用任务 → 自有VD/OES → 单GL上下文
                         ├→ 原内容区/AVC/DCV1 → 仪表
                         └→ 可挂卸的主屏镜像Surface
触摸/Back → 有界本地Binder → 校验UID+会话+页代际 → 自有display
```

镜像页不拥有视频会话，旧页面的detach不能解绑新页。普通VD不使用移除即销毁内容的标志；停止精确归还原业务任务。Meter页面单独按原归属清理。绑定任务的ID/user/root/display保护保留，转发页在绑定前须稳定；无法证明身份时明确停止，不将同包当作可任意接管或删除的授权。图标事件也不直接授权删除任何任务，只处理当前会话的新MAIN/LAUNCHER重复任务并再次读取身份。

本地一次性会话凭据仅防跨进程越权/旧会话串扰，不是视频激活码、付费授权或设备绑定。源APK、第三方反编译代码/资源/授权以及测试夹具不进入公开产品源。

启动信号限定system_server PID、ActivityTaskManager标签和当前包组件，进一步验证同用户MAIN/LAUNCHER、调用UID及单调时间；原始Intent/logcat行不保存、不导出。无关应用不路由；停止终止仅本会话的只读子进程。不注册系统全局ActivityController或替换原厂诊断器。停止背景归还使用精确隔离任务栈，不把业务页面强制提到主屏最前。

## 需要如实验证

Android10输入法、原图标闪现及singleTask迁回延迟存在平台差异；需要目标车机实际观察。私有模拟器的普通EditText不能可靠弹出系统软键盘，**不承诺系统输入法已兼容**；应用自带键盘是另一条路径，仍按实际应用验证。不能把模拟器、单测或代码实现写成所有应用/所有地图实车通过。FLAG_SECURE/DRM和应用自身禁止副屏的限制不会绕过；没有宣称任意应用必定可投。

本版承接原有效内容区：全幅1536×384、中心720×384；1920×720仍为传输缓冲，不把羽化区当可读空间。原里程/原生告警优先、失联恢复、角色切换和清理未知保护保持。驾驶中勿操作选择/设置或观看娱乐视频；不是道路安全认证。
