# 1.12.0 / RWV8 使用及改动

配套更新 APK 与仪表 App。完整仪表 ZIP 保留原 MCU、参考 OS 与启动文件。

## 显示修复

旧版重点修改的3dscreen不是当前默认ADAS更新路径；本版沿实际2D路径，给已注册及后加载的Node2D传播私有投屏模式，分别隐藏普通Car/CarSmall及静态路面。保留原生车道告警、目标车辆、接管提示和车门信息；停止移除覆盖，不回写旧车辆数据。真实告警不是可关闭的装饰。

全幅视频载体1792×448位于(64,112)，玻璃曲线约束的圆角梯形由仪表透明贴图形成，保守清晰区1408×352位于(256,152)。原生续航背景上沿553与视频下沿融合相接。功率、速度下移14设计像素，里程右移30/下移12；原生数字、单位、续航贴图保持。小窗有效720×384，沿用原厂深浅主题融合。地图颜色由地图自身设置控制。

普通应用镜像按主屏实际可用区域重排自己的业务副屏，不把包含系统栏的物理分辨率缩放进操作区。系统栏、其他主屏应用尺寸与仪表1920×720编码尺寸不改；旋转、重新打开镜像时更新，输入映射跟随已确认尺寸。应用自身固定比例/安全窗口限制仍存在。

## 入口

- USB模式改为开关。开=投屏NCM；关=恢复U盘Host。按实际NCM枚举回显，未枚举不能当Host已成功；以仪表提示为准，无需拔线。
- 首页“仪表地图”同键开关；其他会话先完整停止再启动地图。优先定制高德，其次高德，仍支持其他应用选择。可选无障碍监听定制地图原有两个仪表按钮ID，1000ms防抖；不会伪造车辆信号让隐藏按钮出现。
- 定制地图原生副屏和“按屏幕名接入”创建公开名 **fission_dashcast_meter**，可被meterDisplay的fission_匹配找到。遇到其他fission屏拒绝抢占。普通托管副屏不改成此名，避免影响普通应用的布局判断。
- 按屏幕名：先在Dashcast点“按屏幕名接入→开始接入”，再在有此功能的第三方应用中填写上述屏幕名并投屏。此屏在当前会话存在，不是开机常驻服务；按名称自行创建Activity/Presentation的应用才适用。发现第二个应用UID或换应用时停止，先结束再接入下一应用。窗口发现使用有大小/时间限制的Android10字段解析，不能解析会明确失败；没有对外开放任意命令接口。外部应用自己的页面由它管理，退出时不强停外部应用。

## 本轮重点

先确认小窗/全幅普通车模及装饰路面消失，保留告警；检查圆角、续航贴图、里程、功率单位及深浅切换。再从原图标打开普通应用并操作、切走/切回，确认左右黑边、触摸和系统输入。最后检查地图开关、停止再投、带线Host/NCM，以及支持按屏幕名的应用接入。

离线ARM、GLES、软件AVC、JVM和Android29模拟器结果分开记录；均不等同目标QNX/Kanzi或实车硬编验收。目标帧率30，旧实车日志约28～29；本版修正轮询固定延迟累积，不声称已实车达到30。
