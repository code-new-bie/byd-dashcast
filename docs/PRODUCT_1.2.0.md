# 1.2.0：原厂主题融合与大中心窗

本版需要匹配更新 APK（code38）和仪表 App。不是只改 APK 或只有日志的检查包。MCU、参考 OS、Boot、USB角色脚本、媒体库和已打通的 NCM 路线不变；组件工具不含固件，不会生成可刷 FULL。

## 显示改动

- 全屏里程组回到右下独立位置，保留原生 ODO/Trip/EV/HEV 切换及单位；功率、速度数字及单位上移30个模型像素，为里程留位，不伪造车辆数据。
- 复用原厂 `BgBottom_Dark/Light` 色值和原厂顶线。原厂 `state2` 的深浅状态同步到只供融合层使用的继承属性，不发车辆CAN、不按时间猜测；运行中切换主题不需重投。
- 原66矩形改为两个原生半屏材料，平滑融合四边和四角，避免重复角落压暗。遮罩使用原1920×720 framebuffer像素坐标，不依赖纹理UV翻转；新 GLSL 保留原 TextureBrush 的顶点/材质统一变量元数据。
- 关闭“导航仪表布局”改用 `(576,128,768,432)` 大中心窗。真实副屏以1280×720排版，经独有 EGL 输入变换送入原1920×720编码器，仪表缩放后横纵比例相同，不将8:3宽图直接压扁到16:9。
- 中心窗同样位于原生前景下方，仪表显示相应开口和24像素柔和边界；采用原尺寸/来源的车速功率，告警、车门/驻车等原生父组不隐藏。旧640×240工程窗口仍保留。

这是复用原主题配色与信息层次，不是将原整张不透明背景重新打开，也不是声称复刻所有原厂背景纹理或具有实时高斯模糊。地图自己的昼夜颜色仍由导航应用控制；APK浅色开关只影响APK界面。

## 生命周期与兼容

两种产品模式都用同一 DCV1/3 连接、所属续租、首源就绪门槛和独立五秒失联恢复，无累计时长上限。START新增精确旗标2，仅允许固定中心窗；旧旗标0/1保持。BGP START中5001仅是中心样式选择符，实际租约仍5000ms，续租仍5000；不是延长时限。错误owner、主题代次/进程变化、未确认清理及物理失联保护继续保留，不盲目强切Host。

## 使用

停止旧会话后覆盖更新配套APK和仪表App。设置中“导航仪表布局”开启为全屏，关闭为大中心窗，切换设置后重新开始。投屏运行中切换仪表原厂深浅模式，看衬底/四边是否随之变化；地图昼夜需在导航应用内配置。检查右下里程和单位、停止/断线后恢复及再次开始。

已有独立副屏、Host/NCM与正常退出实车基线保持。本版新材料/中心窗 Android EGL 与 QNX 实际混合尚待实车确认，桌面 GLES 编译链接/ARM-Thumb模拟/资源审计不代替目标机 GPU、全部动态告警、稳定30FPS或道路认证。1.1.2实车约9分45秒正常停止是之前版本的基线，不冒充本版现场验收。
