# Dashcast 仪表投屏

把 BYD 车机（Android 10）上的应用投到 QNX 数字仪表上显示，通过一根 USB 数据线连接。目标车型为 2021 款宋 Plus DM-i。

当前版本：APK **1.25.0 / code80**，配套仪表 **1.25.0/RWVH**，两端必须同时更新。本次修复全屏投屏中切换仪表样式的几何冲突，见 [1.25.0](docs/PRODUCT_1.25.0.md)；上版见 [1.24.0](docs/PRODUCT_1.24.0.md)。车机桌面上的名称是“仪表投屏”。

## 能做什么

- 选一个车机应用投到仪表，全屏或小窗两种布局。应用在专用虚拟屏上运行，车机主屏的投屏页里嵌着同一画面，可以直接操作。
- 投屏时仪表原有的车速、功率、电量等信息继续由仪表自己显示，盖在视频上方；告警优先显示。停止后恢复原厂画面。
- 仪表的深浅主题会同时作用于投屏边框；本应用界面默认跟随车机的深浅设置。
- 定制版高德地图走它自己的仪表界面，地图自带的仪表按钮也可以直接使用。支持外部屏幕的应用，可以通过“应用内投屏接入”提供的 `fission_dashcast_meter` 屏幕发送画面。
- 视频不需要激活码或设备绑定，用到的是车机正常的 ADB 调试和 USB 访问授权。

不是所有应用都能投屏：禁止副屏显示的应用、系统软键盘等仍有限制。本项目也没有经过道路认证。

## 目录

| 目录 | 内容 |
|---|---|
| `android/` | 车机 APK 源码（Kotlin/Java）与单元测试 |
| `instrument/` | 仪表端：QNX 脚本、接收端和 HMI 的 ARM/Thumb 补丁源码、遮罩图、便携背景控制器，见[说明](instrument/README.md) |

| `tools/` | 构建仪表组件的命令行工具、公开内容检查、测试 |
| `assets/backgrounds/` | 投屏背景原图（本项目自行设计） |

## 快速开始

```bash
cd android
bash gradlew testDebugUnitTest assembleDebug lintDebug --console=plain
```

需要 JDK 21 和 Android SDK 35。仪表组件要用你自己的固件原件构建，见[构建文档](docs/BUILD.md)。

## 安全与边界

- 在不分心的场景下选择应用和修改设置。驾驶中只用导航，不要看娱乐视频。软件拿不到可信的车速和挡位信号，不会假装知道车辆状态。
- 仪表重要信息异常、窗口没有退出或模式异常时，停止使用，按正常流程重启或刷回原包。
- 仓库不包含任何固件、APK、签名密钥、ADB 身份或实车日志。
